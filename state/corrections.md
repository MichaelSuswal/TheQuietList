# Corrections log

Every fix to the record: what was wrong, what it is now, and the proof (the chat message or file the player pointed to). Anything built on the bad fact gets reworked, and the rework is noted here.

Authority, in order: what the player points to in the chat; then this repository; then the narrator's memory, which is never an authority on its own.

Format: `date · day N · was · now · proof · reworked`
